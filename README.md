# website

Die Homepage von https://www.mitwachsen-spiele.de/: ruhige Spiele für Kinder ab 3 Jahren, die man zusammen mit Mama oder Papa spielt.

Die Seite zieht gerade aus [larmic/mitwachsen-spiele](https://github.com/larmic/mitwachsen-spiele) hierher um, bis dahin liefert weiter das alte Repo aus. Das Spiel selbst liegt in [mitwachsen-spiele/weltenbummler](https://github.com/mitwachsen-spiele/weltenbummler). Fortschritt: larmic/mitwachsen-spiele#71.
